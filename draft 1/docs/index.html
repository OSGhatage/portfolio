How the work is done

Analysis is reproducible rather than anecdotal. Inputs are named with a source link, the method is stated in short, and each result is checked against an independent reference with the agreement figures written down. Where a limitation is known, it is written down too.

How I deliver covers formats, coordinate reference systems, licensing and validation statements.
