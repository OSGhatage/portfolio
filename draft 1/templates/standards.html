How I deliver

The same rules on every job, stated up front, so nothing about the format of a deliverable has to be negotiated after the analysis is done.

Formats

Delivered as the format asked for; where no format is specified, this is the default set.

  • Cloud-Optimized GeoTIFF — rasters, tiled and with overviews where the size warrants it.
  • GeoPackage — vector layers, with a consistent layer and field naming scheme.
  • GeoJSON — vector for interchange, where a web-friendly format is needed.
  • LAZ — lidar point clouds, kept in the compressed form.
  • CSV with a data dictionary — tabular output always ships with a companion dictionary defining every field, its units and its type.
  • STAC or ISO-lite metadata — a STAC item, or an ISO 19115-style record, alongside the data itself.

Coordinate reference system

The client's pipeline comes first. If your system already has a convention, the output conforms to it and no separate choice is made. Otherwise:

  • WGS 84 (EPSG:4326) for interchange and web delivery, and a local UTM zone for anything involving distance, area or shape measurement.
  • The CRS actually used is recorded in the output metadata and written down in the delivery note. It is never left implicit.
  • Where an input or reference dataset carries its own CRS, that is honoured rather than silently reprojected.

Licensing

Every deliverable carries an explicit licence line naming the licence and who holds copyright. Where client data was supplied under NDA, the licence names the client as the rights holder and states the permitted use.

Validation

Every map ships with a validation statement. That means the reference used for checking, the sample size, and the agreement figures, written in full rather than summarised. Where no independent reference exists, that is stated as well — an unvalidated result is labelled unvalidated.

Data policy

Work is done on open data: Sentinel, Landsat, OpenStreetMap and similar public sources. Proprietary data is used only when a client supplies it under NDA, in which case it is not redistributed and is not shown on this site.
